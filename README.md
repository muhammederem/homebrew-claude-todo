# homebrew-claude-todo

Homebrew tap for [Leftovers](https://github.com/muhammederem/claude-todo) (formerly Claude To-Do).

```sh
brew tap muhammederem/claude-todo
brew trust muhammederem/claude-todo   # newer Homebrew only loads casks from third-party taps you trust
brew install claude-todo
```

App: https://github.com/muhammederem/claude-todo
